1. Адреса моєї сторінки — http://127.0.0.1:5500/index.html. Вона складається з протоколу http, адреси сервера 127.0.0.1, порту 5500 та назви файлу index.html.

2. Браузер зробив 2 основні запити: один для завантаження HTML-сторінки, а другий для зображення images.jpg. Кожен файл, який потрібен для відображення сторінки, браузер завантажує окремим запитом.

3. Коли я вказала неправильний шлях до зображення, воно перестало відображатися на сторінці. У вкладці Network з'явився запит зі статусом 404, який означає, що файл не знайдено.

4. Тому що зміни через DevTools застосовуються лише в браузері та не змінюють сам HTML-файл. Після оновлення сторінки браузер знову завантажує початковий файл, тому ці зміни зникають.

5. У цій схемі клієнтом є браузер, який надсилає запити на отримання сторінки. Сервером є мій комп'ютер, на якому запущено Live Server і зберігаються файли сайту.
